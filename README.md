# 奶茶机器人 (Milk-tea-robot)

奶茶机器人主控固件（Arduino Mega 2560）。

## 文件说明

- `完整联动代码/v1.0.txt` — 主控固件 v1.0（单文件，Arduino 代码），主要功能：
  - HX711 秤称重（净重出液、自动去皮）
  - DP1 隔膜泵（茶汤出液）
  - PP1 蠕动泵（竹蔗冰糖浆，RS485 控制，带回吸）
  - 气缸点动控制（取杯）
  - 订单流程控制、错峰出液、分泵到量停止、急停等

## 硬件

- 主控：Arduino Mega 2560
- 接线说明详见代码头部注释

## 使用

- 将 `v1.0.txt` 内容复制到 Arduino IDE 新建工程（或改名为 `.ino`）即可编译
- 调试命令：`DEBUG` 进入调试 / `RUN` 存 EEPROM 退出 / `r` 急停
