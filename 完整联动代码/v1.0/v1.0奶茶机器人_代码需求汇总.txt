【一】最初 7 条要求（代码要求.txt 原文需求）
--------------------------------------------------------------------------------
1. 查表法配方
   用枚举 + 配方表写每个品类奶茶的需求，按"饮品 × 杯型 × 甜度"索引，
   数值直接查表不现算，查表函数输出配方喂给状态机。

2. 可扩展泵
   以后会加隔膜泵和蠕动泵；查表必须能区分"不是每个泵都出液"
   （例如某款茶 = 隔膜泵1 + 隔膜泵6 + 蠕动泵5）；
   预留加泵代码位置，最后要给加泵示例。

3. 泵的命名
   英文区分类型，编号在后面，例如 隔膜泵1、隔膜泵2。

4. 可扩展品类
   配方表预留空位，以后加新品种，并给出新增奶茶的示例代码。

5. 整机框架
   cmd 输入 奶茶编号 + 杯型 + 甜度
   -> 空杯放到 HX711
   -> 一系列判断与算法
   -> 泵出液（配方数值先填占位、标明在哪里改）
   -> 出液完成后 10 秒，气缸点动 500ms
   -> 完成。

6. 蠕动泵 Modbus
   正常只需 开启/停止；正转、反转、转速、圈数等属于调试功能。
   需要"正常 / 调试"两种状态，cmd 切换。
   从调试退出回正常时，调试好的参数必须应用到正常状态（不能白调）。

7. 调试范围
   既能调试每个蠕动泵的功能，
   也能调试每款茶对应泵的出液量。


【二】硬件接线（已确认）
--------------------------------------------------------------------------------
板子：Arduino Mega 2560

HX711 称重模块（1 台，一次只做一杯）
  DT  -> D2
  SCK -> D3
  VCC -> 5V
  GND -> GND

隔膜泵 DP1（茶汤）
  继电器 IN1 -> D6
  继电器型号 SRD-24VDC-SL-C
  跳线帽插 H 档，IN 高电平吸合，光耦隔离

气缸阀 VALVE
  继电器 IN2 -> D7
  单线圈：通电伸出 / 断电回位 / 点动 500ms

蠕动泵 PP1（竹蔗冰糖浆），经 485 转 TTL 模块
  EN  -> D8
  D18(TX1) -> 模块 RXD
  D19(RX1) -> 模块 TXD
  模块 VCC -> 5V，GND -> GND
  485 A/B 接泵 A/B
  从站地址 0x01
  波特率 115200，8N1
  EN 高电平 = 发送
  转速 36000（单位 0.01rpm，即 360.00 rpm）
  正常出液方向 = 逆时针

继电器触点侧
  COM1、COM2 接 24V 正极
  NO1 -> 隔膜泵正极，NO2 -> 气缸电磁阀正极
  泵/阀负极 -> 24V 负极

命名确认
  diaphragmPump1  (DP1 / D6)
  peristalticPump1(PP1 / 485)
  预留数组位置，以后加泵只改安装表


【三】点单与配方
--------------------------------------------------------------------------------
点单格式：4 个数字 —— SKU 杯型 糖度 冰
  示例： 1 1 0 0
  杯型：0 = 中杯 M，1 = 大杯 L
  糖度：0 = 少糖，1 = 正常糖，2 = 多糖
  冰  ：0 = 去冰，1 = 加冰
  当前第 4 位固定 0（去冰）；加冰只留接口，等制冰机。

品类
  当前只有 SKU1 = 糯香柠檬茶（原"柠檬茶""奶茶"作废）
  SKU2 ~ SKU5 全部留空，预留加品类

配方数据（DP1 = 茶汤 g，PP1 = 竹蔗冰糖浆 g）
  中杯 M 去冰：
    少糖   茶汤 356.5 / 糖浆 24
    正常糖 茶汤 340.5 / 糖浆 40
    多糖   茶汤 324.5 / 糖浆 56
  中杯 M 加冰（制冰机未装，先不做加冰单）：
    少糖   茶汤 276.5 / 糖浆 24
    正常糖 茶汤 260.5 / 糖浆 40
    多糖   茶汤 244.5 / 糖浆 56
  大杯 L 去冰：
    少糖   茶汤 536 / 糖浆 34
    正常糖 茶汤 514 / 糖浆 56
    多糖   茶汤 492 / 糖浆 78
  大杯 L 加冰：
    待补数据（空配方，点到直接拒单，不出液）

加冰说明
  配方里 ice 只是"要加冰"的标志，记录并打印，
  当前不驱动任何输出；doIce() 为空函数接口，制冰机到了只改这里。

称重语义
  空杯放上后自动 tare，目标克数 = 净出液重量（不含杯重）。


【四】出液算法
--------------------------------------------------------------------------------
多泵同时开
  启动错峰 150ms（算"同时"），停泵不错峰。

模式 A（已标定 g/s 后）
  每泵按 g/s × 已运行时间 估算自己的出液量，
  估算到"目标 - 提前量"就停该泵；
  秤的总重只做兜底：
    总重达到配方总和 -> 所有泵全停
    超出配方总和 +10g -> 立即全停（防溢出）

模式 B（g/s 未标定，=0 时）
  两泵同开，总重到配方总和一起停，先把流程跑通；
  标定完成后自动切换到模式 A。

提前量
  隔膜泵 DP1 = 5g
  蠕动泵 PP1 = 1g

蠕动泵方向与回吸
  正常出液方向 = 逆时针（寄存器 0x0065 写 1）
  正反转报文（动态算 CRC）：
    逆时针 CCW：0x0065 写 0x0001
    顺时针 CW ：0x0065 写 0x0000
  泵停后自动回吸 300ms；
  另有手动"持续回吸"，人工看到回吸完再发 STOP（用于清洗管路）。
  圈数功能用不到（按 g/s 停），常量保留、菜单隐藏。

流量标定
  自动标定 CALF：跑 N 秒 -> 读秤增量 -> 算 g/s -> 存 EEPROM
    CALF DP1 默认 3 秒（10 秒会溢出杯子）
    CALF PP1 默认 5 秒
    标定过程总重 >450g 自动停
  也可手填：FLOW PP1 2.8
  没标定(0)时用模式 B，标定后自动用模式 A。

寄存器地址（蠕动泵）
  0x0064 转速（0.01rpm）
  0x0065 方向（1=逆时针，0=顺时针）
  0x0066/0x0067 圈数（32位，本次不用）
  0x0068 控制（1=启动，2=持续回吸，0=停止）


【五】正常流程（逐状态）
--------------------------------------------------------------------------------
1. 待机 IDLE：空秤，不发 ORDER 不动。
2. 下单 -> WAIT_CUP：打印配方，20 秒内必须放空杯（超时订单作废）。
3. 放杯确认：重量 >=14g 持续 800ms 且期间波动 <1g
   -> 自动 tare 去皮 -> 进入出液。
4. 出液 FILL：DP1 与 PP1 错峰 150ms 同时启动。
5. 停泵：按模式 A/B 判别，全部停（含回吸结束）。
6. 判稳 SETTLE：波动 <0.5g 持续 800ms（等余液滴落），最长等 15 秒。
7. 等待移杯 WAIT_MOVE：10 秒（杯子在此期间移到压盖工位；10 秒到就动，不依赖秤）。
8. 压盖 VALVE：气缸点动 500ms。
9. 完成 FINISH：检测杯子取走（读数 <= 负杯重，约 -8g）
   -> 自动 tare -> 回待机。
10. 每杯必须重新发 ORDER 才能做下一杯。

异常保护（统一处理：全部泵停 + 气缸不动 + 报故障）
  出液中杯子被取走
  8 秒窗口内总重增量 <8g（空转 / 堵管 / 缺料）
  单泵运行超时 45 秒
  蠕动泵连续 3 次 Modbus 无应答


【六】调试模式
--------------------------------------------------------------------------------
进入：DEBUG
  - 空闲时直接进入
  - 正在制作时：做完手上这一杯才进入，后续订单暂停
  - 紧急情况不排队，直接发 r 立即全停
退出：RUN
  - 保存改动到 EEPROM（掉电不丢）
  - 应用到正常模式
  - 若秤上有杯 -> 报故障，不退出
调试期间禁止自动流程（放杯不会自己开泵）。

调试命令清单
  隔膜泵：DP1 ON / DP1 OFF / DP1 T 秒
  蠕动泵：PP1 GO / STOP / BACK / SPEED n / DIR CW|CCW
  气缸  ：VALVE ON（伸出）/ OFF（缩回）/ T（点动 500ms）
  标定  ：CALF DP1 3 / CALF PP1 5
  流量  ：FLOWS 查看全部 g/s / FLOW PP1 2.8 手填
  秤    ：TARE 去皮 / CAL 200.0 校准（先 TARE，再放砝码）
           RAW 打印原始值（再发一次关闭）
  配方  ：RCP 1 1 0 0 PP1 15 PP2 30   （一条到底）
           RCP 1 1 0 0                 （不带泵对 = 打印该行）
  参数  ：SET WAITCUP|MOVE|VALVE|SUCK 毫秒
           SET TRIG 14 / SET NOFLOW 8000 8
  出厂  ：RESETCFG（恢复默认配方与参数，CAL 校准值不重置）
  Modbus：SCAN（1200~115200 扫描找波特率，默认 115200）
           BRIDGE（串口透传，发 +++ 退出；用电脑 Modbus 助手直连泵）
           PARITY N|E|O
           BAUD 115200
           STATUS（从站/波特率/校验/转速/失败计数/各时间参数/校准系数）
  通用  ：S 状态 / HELP 命令表 / r 急停


【七】Modbus 命令保留决定
--------------------------------------------------------------------------------
保留
  SPEED    写 0x0064 转速
  GO/START 写 0x0068 = 1 启动
  STOP     写 0x0068 = 0 停止
  BACK     写 0x0068 = 2 持续回吸，直到再写 0
  REV/FWD  正反转（0x0065，1=逆时针 0=顺时针）
  SCAN     扫描波特率，默认 115200
  BRIDGE   透传（+++ 退出）
  PARITY   N / E / O
  BAUD     运行时改波特率
  STATUS   打印通信与参数状态

删除
  CRCCHK   原固定报文 CRC 校验（改为全部动态算 CRC）
  FIXED    原样发硬编码报文的命令
  SEQ      一键 转速->圈数->启动->2s->停
  EN       手动强制方向脚电平
  ENAUTO   方向控制方式切换

说明
  原 STOP 与回吸两条固定报文 CRC 是错的
  （正确为 08 16 与 89 D7），
  新固件全部动态计算 CRC，不再硬编码。


【八】其他工程要求
--------------------------------------------------------------------------------
- 全部非阻塞：用 millis 计时，不用 delay 卡住串口和定时。
- 串口命令统一转大写匹配（因此急停需同时接受 r / R）。
- 以后加蠕动泵：一台泵配一个 485 模块、各占一个串口
    PP2 = Serial2 (D16 RX2 / D17 TX2) + EN D9
    PP3 = Serial3 (D14 RX3 / D15 TX3) + EN D10
    多泵共用同一条 485 总线（不同从站地址）的方案以后再议。
- 代码末尾必须给出：
    加隔膜泵示例
    加蠕动泵示例
    加品类示例
    制冰机接入位置
    g/s 标定量填写方法
- 继电器板 SRD-24VDC-SL-C 为 24V 线圈，
  若出现"发了命令泵不动"，先量 IN 脚 5V 时是否真的吸合，
  必要时在 IN 前加三极管/MOSFET 或换 5V 输入版继电器板。
- 供电：24V 动力与 Mega 5V 分开供电，GND 单点接地，
  继电器触点 COM-NO 并 RC 吸收（100Ω + 0.1µF/630V），
  电磁阀线圈并续流二极管。
